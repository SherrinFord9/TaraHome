Home Assistant Shopping List: Share It Across Phones

One grocery list for the kitchen and both phones, with a clear plan for the supermarket’s dead spots.

By Tara Home

TLDR

  • Start with the built-in Shopping list. Put the same list on both phones and your kitchen dashboard; you do not need a custom card.
  • Test away from home before shopping. The Home Assistant app needs a working connection to your server. A local list is not automatically an offline phone list.
  • Plan for no signal. Save a screenshot before leaving, or use a separate phone list app with a verified offline workflow. A screenshot will not sync purchases.
  • On iPhone, Reminders Sync is an optional bridge. It needs a compatible Companion app and Reminders permission; background updates are not guaranteed to run immediately.

Use one list, then check how each phone reaches it

For a shared Home Assistant shopping list, start with the built-in Shopping list integration. An integration is a connection or feature added to Home Assistant. Both household members should open the same list on the same Home Assistant server. Creating two lists with the same display name does not connect them.

First add a harmless test item at home and check it off from the other phone. Next test with the shopper’s Wi-Fi off and mobile data on. Only after that should you decide whether the supermarket needs an offline fallback.

The list can live on your own Home Assistant server, but your phone still has to reach that server to read current items and save changes. Local storage describes where the list lives; offline access describes what the phone can do without a connection. These are separate choices.

OurGroceries is an alternative storage choice, not an automatic copy of the built-in Shopping list. Its integration creates entities for its own lists. The vendor’s FAQ covers phone support, sharing and payment options. This guide does not claim a tested offline experience for that app.

2. Open the same list on both phones

  1. Find the existing list. Open To-do lists in Home Assistant’s sidebar and look for Shopping list. If missing, an administrator can add Shopping list under Settings → Devices & services → Add integration.
  2. Use separate household logins. Have an administrator create a login for each trusted household member, then connect each Home Assistant phone app (the Companion app) to this server. Everyday use normally does not need administrator status. Follow the account documentation.
  3. Add one visible card. On an editable dashboard, select Edit dashboard → Add card → To-do list. Choose the actual Shopping list entity and save. An entity is Home Assistant’s identifier for one list or device function.
  4. Check the second phone. Open that dashboard or the sidebar’s To-do lists page and select the same list. Different dashboard layouts are fine; the selected entity must match.

A typical list identifier is todo.shopping_list, but check yours instead of assuming the name. The standard card supports adding, editing and checking off items. If you prefer its code editor, this is the complete card configuration; it belongs in a dashboard card, not configuration.yaml:

type: todo-list
entity: todo.shopping_list
title: Groceries
hide_completed: false

Leave completed items visible during setup so you can see where a checked item went. Later, hide_completed: true hides that section without deleting its items.

A grocery dashboard is not a grocery-only account. Hiding other tabs does not prevent access to their URLs, and a non-admin login does not establish list-only authorization. Give Home Assistant accounts only to people you trust with the access they actually receive. For a guest who needs just groceries, use a list-sharing service rather than assuming dashboard visibility creates a security boundary. See the official view-visibility note and our guide to Home Assistant user restrictions.

4. Separate remote access from no-signal shopping

If it works on home Wi-Fi but fails on mobile data, fix the remote connection first. The Companion app networking guide explains why a private home address is not enough from outside the house. Home Assistant Cloud provides a paid remote-access option; a correctly configured VPN—a private connection back to your home network—is another route. Our remote-access guide compares those choices.

Neither route creates a connection in a supermarket dead spot. For an occasional trip, open the current list before leaving and save a screenshot that includes every active item. Treat it as a dated copy: it cannot receive Alex’s last-minute additions or record Sam’s purchases back to Home Assistant.

For regular disconnected shopping, choose a phone app that keeps a usable local copy and verify its return-to-online behavior. Test only grocery entries: temporarily turn off that phone’s Wi-Fi and mobile data, open the list again, and check whether you can read and complete a test item. Restore connectivity and check the other person’s list. A cached screen by itself does not prove that changes will sync.

Optional on iPhone: connect Apple Reminders

The iOS Companion app includes Reminders Sync from version 2026.8.0, marked LABS (experimental). The maintainer’s setup documentation is still a draft; the feature is present in the released 2026.9.2 app source. Settings can change between versions.

  1. Start with an empty test list in Apple Reminders and a separate Local to-do test list in Home Assistant.
  2. In the iPhone’s Home Assistant app, open Companion app settings → Reminders Sync and grant the requested full Reminders access.
  3. Add a pairing, select those two lists, and choose Two-way if both sides should accept edits. Save, then use Sync now.
  4. Add one test item in each app and complete one. Confirm the other side agrees before connecting a real household list. Two-way sync can also propagate deletions.

This connection runs through the phone. In the checked release, scheduled foreground checks and background refresh are off by default; opening the app or choosing Sync now can fetch updates. If background refresh is enabled, iOS still decides when it runs. Open the app and verify the list before leaving and after reconnecting. Do not assume every Reminders feature, such as recurrence or location alerts, transfers.

Pairing Reminders with Home Assistant also does not share an Apple list with another person. Set up household sharing in the chosen app separately, and repeat the two-person and disconnected checks. This optional path is not needed for two connected Home Assistant phones.

Frequently asked questions

Can I add groceries by voice?

Yes. The built-in Shopping list supports Assist commands such as “Add eggs to my shopping list.” First check the destination using Assist’s text input. A working grocery list does not by itself configure microphones or speech processing; our local voice setup guide covers those separate parts.

Does sharing the built-in list require a subscription?

The list itself does not. Both phones need access to the running Home Assistant server. Remote access may have a separate cost, depending on the route you choose.

Can I use this for recurring household chores?

A checklist and a recurring schedule are different jobs. For “remind me again two weeks after I finish,” use our completion-based chore reminder guide. A grocery checkbox alone does not create that schedule.
